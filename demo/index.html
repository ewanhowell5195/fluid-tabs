fluid-tabs

A lightweight, zero-dependency tabs library with a smooth animated indicator, drag/wheel/swipe scrolling, and multiple visual styles.

Just add the tab-bar class to a row of buttons.

GitHub NPM JSDelivr Vue

Features

  • No dependencies
  • Works with mouse, touch, and keyboard
  • Six built-in styles to restyle from
  • Horizontal or vertical, switchable by screen size
  • Animated indicator with an elastic stretch and hover tease
  • Panels cross-fade and resize between tabs
  • Overflowing tabs scroll with momentum, or wrap onto new rows
  • Swipe between tabs on touch
  • Screen reader support and right-to-left layouts
  • Customizable via CSS variables
  • Vue component available

Panel Transitions

Panels slide and fade by default. Set --tab-panel-distance on the .tab-contents to change how far they slide, or 0 to just fade. Each panel also gets --tab-panel-x, which is -1 before the active tab, 0 when active, and 1 after it, so anything inside it can move on its own:

Panels with their own backgrounds let the page show through as they cross-fade. Set --tab-panel-blend: plus-lighter on the .tab-contents to stop that, as all three cards do. The .tab-contents can't have a background of its own:

.panels-with-backgrounds {
  --tab-panel-blend: plus-lighter;
}

.fade-only {
  --tab-panel-distance: 0;
}

.background-fades > .tab-content {
  transform: none;
}

.background-fades .content {
  transform: translateX(calc(var(--tab-panel-x) * 64px));
  transition: transform var(--tab-transition-duration) var(--tab-transition-easing);
}

Swiping

On a touch screen, swipe left or right across the panels to move between tabs. Swiping doesn't do anything with a mouse on desktop, so try this one on your phone. Add data-tab-no-swipe to turn it off, for example when a panel has its own carousel:

Events

The bar fires a tab-changed event when the active tab changes, with the new tab's data-tab in event.detail. Panels are optional, so a bar on its own works as a filter. Here there are no panels, the event just hides the messages that don't match:

Nina Design review notes09:41
Tom Lunch on Friday?Yesterday
Sam Flights are bookedTuesday
Newsletter This week's top storiesTuesday
Billing Your invoice is readyMonday
bar.addEventListener("tab-changed", e => {
  for (const message of messages) {
    message.inert = !message.dataset.filter.includes(e.detail)
  }
})

Adding & Removing Bars

Use FluidTabs.init() to set up bars added after the page loads, and bar.destroy() to clean one up before removing it:

FluidTabs.init()          // whole document
FluidTabs.init(sectionEl) // within an element

bar.destroy()

Customization Variables

Fine-tune the feel with CSS variables, globally or per bar. Colours, radii, and spacing are plain CSS, as the scenes in Demos show:

Slow and springy

No elastic stretch

No hover tease

Bouncy easing

.tab-bar {
  --tab-transition-duration: .25s;                     /* Duration of every transition */
  --tab-transition-easing: cubic-bezier(.4, 0, .2, 1); /* Easing of every transition */
  --tab-slide-lag: .333;                               /* Elastic stretch, as a fraction of the duration */
  --tab-tease-x: 10px;                                 /* How far the indicator stretches on hover */
  --tab-fade: 60px;                                    /* Width of the scroll edge fade */
}
